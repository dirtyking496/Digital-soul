# ForgePocket V1
Application web installable sur Android (PWA), construite en mode local-first.

Fonctions : génération de trois modèles HTML, éditeur, aperçu sandboxé, sauvegarde locale, validation API, export HTML autonome, cache PWA.

Limites : pas encore d'APK natif, de synchronisation multi-appareils, de comptes, de portefeuille réel, de paiements ou de marketplace. Les crédits d'interface sont une démonstration uniquement. Les projets sont sauvegardés dans le navigateur de l'appareil.

Développement : Node.js 20+, npm install, npm start.
